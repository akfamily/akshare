欢迎访问 AKShare 在线文档！
===========================================

AKShare 是基于 Python 的开源财经数据接口库，提供股票、期货、期权、基金、债券、外汇、宏观经济等 1000 余个数据接口，返回结果均为带中文列名的 pandas DataFrame。

- 第一次使用：先阅读 :doc:`installation` 和 :doc:`tutorial`
- 查找接口：使用 :doc:`registry`，或浏览 :doc:`data/index`
- 遇到问题：查看 :doc:`answer`，或在 `GitHub Issues <https://github.com/akfamily/akshare/issues>`_ 中反馈
