(interest_rate_repo_hist_cm)=
## 回购定盘利率-历史

接口：interest_rate_repo_hist_cm

目标地址：https://www.chinamoney.com.cn/chinese/bkfrr/

描述：回购定盘利率数据

限量：单次返回指定日期间（一年）的所有历史数据

输入参数

| 名称         | 类型  | 描述                                     |
|------------|-----|----------------------------------------|
| start_date | str | start_date="20200930"；开始时间与结束时间需要在一年内 |
| end_date   | str | end_date="20201029"；开始时间与结束时间需要在一年内   |

输出参数

| 名称     | 类型      | 描述      |
|--------|---------|---------|
| date   | object  | -       |
| FR001  | float64 | 注意单位：% |
| FR007  | float64 | 注意单位：% |
| FR014  | float64 | 注意单位：% |
| FDR001 | float64 | 注意单位：% |
| FDR007 | float64 | 注意单位：% |
| FDR014 | float64 | 注意单位：% |

接口示例

```python
import akshare as ak

interest_rate_repo_hist_cm_df = ak.interest_rate_repo_hist_cm(start_date="20231001", end_date="20240101")
```
